Модуль IMG.h IMG.cpp содержит:
- Функции загрузки, копирования, хранения и доступа к пикселям изображения;
- Функции монохромизации и наложения цветовой маски на изображение;
- Функция рисования линий на изображении;
- Функции изменения яркости и контраста.

Модуль Segmentation.h Segmentation.cpp содержит:
- Функцию расчёта свёртки (Convolution);
- Функции определения границ элементов изображения (DetectBorders и FastDetectBorders);
- Функцию получения кластеров изображения (выделение изолированных фрагментов на однородном фоне) GetClusters;
- Функцию вычитания иображений Difference.

Модуль IMGtoVector.h IMGtoVector.cpp  содержить функции векторизации монохромного растра.
